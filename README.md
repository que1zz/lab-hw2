# Домашнее задание к работе 2

## Условие задачи

Стоимость погонного метра красного шелка стоит **x** золотых. Сколько заплатил Грей за ткань для своей бригантины, если общая площадь парусов на ней **s** м², а ширина ткани в рулоне **l** см?

## 1. Алгоритм и блок-схема

### Алгоритм

1. **Начало**
2. Задать исходные данные:
   - `x` — цена погонного метра красного шелка (золотых).
   - `s` — общая площадь парусов (м²).
   - `l` — ширина ткани в рулоне (см).
3. Перевести ширину ткани из сантиметров в метры:
   - `shirina` = `l` / 100
4. Вычислить длину ткани (погонных метров):
   - `dlina` = `s` / `shirina`
5. Вычислить стоимость ткани:
   - `stoimost` = `dlina` * `x`
6. Вывести результаты расчетов с подстановкой всех значений в текст.
7. **Конец**

## 2. Реализация программы

```c
#include <stdio.h>
#include <locale.h>

int main()
{
	setlocale(LC_ALL, "Russian");
	float x = 1200.0; // цена погонного метра красного шелка (золотых)
	float s = 150.0;  // общая площадь парусов (м2)
	float l = 90.0;   // ширина ткани в рулоне (см)

	//sm v m
	float shirina = l / 100;
	//nah. dlinu
	float dlina = s / shirina;
	//nah. stoimost
	float stoimost = dlina * x;

	printf("РАСЧЕТ СТОИМОСТИ ШЕЛКА ДЛЯ ПАРУСОВ БРИГАНТИНЫ\n");
	printf("=============================================\n\n");

	printf("УСЛОВИЯ:\n");
	printf("- Стоимость погонного метра красного шелка: %.2f золотых.\n", x);
	printf("- Общая площадь парусов: %.2f м2.\n", s);
	printf("- Ширина ткани в рулоне: %.0f см = %.2f м.\n\n", l, shirina);

	printf("РАСЧЕТ:\n");
	printf("- Длина ткани: %.2f м2 / %.2f м = %.2f погонных метров.\n", s, shirina, dlina);
	printf("- Стоимость ткани: %.2f м * %.2f золотых/м = %.2f золотых.\n", dlina, x, stoimost);

	printf("=============================================\n");
	printf("ГРЕЙ ЗАПЛАТИЛ ЗА ТКАНЬ ДЛЯ ПАРУСОВ: %.2f золотых.\n", stoimost);

	return 0;
}
```
